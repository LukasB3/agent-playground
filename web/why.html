App Generator

Why I built this

This site is a small, public proof of a bigger claim: today's AI coding agents can build real software end to end, and they can do it safely on infrastructure you control.

What it demonstrates

Every app here is written by an agent that nobody supervises. A request comes in, the agent writes the code in a locked-down container, plain code checks the result, and the app goes live. The interesting part is not the apps. It is the pipeline around the agent: the sandbox, the key handling, the checks, the limits, the automatic publishing. That is the work that turns "an AI can write code" into something you can actually put in front of strangers.

Why only small web apps

The generator is deliberately limited to single-page apps in the browser. Two reasons: it is open to everyone, so every job costs me tokens, and it exists to demonstrate the approach, not to host your product. The limits keep the demo cheap and the attack surface small.

What the same approach can do

None of the pieces are tied to toy apps. The same pattern scales to medium-sized applications: a database, an API, authentication, background jobs, tests, deployment. Running on company infrastructure, with the company's own repositories, CI and secrets handling, an agent can build and extend such systems while the guard rails decide what actually ships.

  • Internal tools and dashboards that read from your existing databases
  • Services with a proper backend, data model and API
  • Automations that connect systems you already run
  • Prototypes that become real products instead of being thrown away

The agent does the writing. The architecture around it, which is the part I enjoy building, makes sure the output is checked, reproducible and safe to run.
